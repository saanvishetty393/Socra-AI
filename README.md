# Socra – AI Tutor

Socra is an AI tutor website that helps students learn concepts through guided conversation. A student picks a topic, chats with the tutor, takes a short quiz, and tracks their progress.

This is the Milestone-1 MVP. It has no backend: all data is dummy data, and app state is shared with React Context.

## Features
- Landing page explaining the product
- Mock login and registration with form validation
- Dashboard with streak, stats, recommended topics, and weak topics
- Topic library with search and filters
- Tutor chat with scripted replies, typing indicator, and quick-action chips
- Quiz with instant feedback, explanations, and a results screen
- Progress page with mastery levels and quiz history
- Light and dark mode

## Architecture
```
Next.js
   ↓
Pages (app/)
   ↓
Components (components/)
   ↓
React Context (context/)
   ↓
Dummy Data (data/)
```

- **AuthContext:** user, login, register, logout
- **LearningContext:** topics, chat history, quiz results, progress
- **ThemeContext:** light and dark theme

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/saanvishetty393/Socra-AI.git
   cd Socra-AI
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

Use any valid email and a password of 6 or more characters to log in, since authentication is mocked.
